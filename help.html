CMG Report Builder

Prototype v0.1. Test in a copy first.

Use Add Project to append a card. Use Refresh Projects and Load Project to edit a builder card. Apply Update changes only edited fields. Existing call-sheet text is not automatically migrated.

Dates use YYYY-MM-DD. Percent Complete uses a whole number from 0 to 100. Reload before updating a card another person is editing.

Director summary and department tables are edited directly in Word. There is no automatic director-summary calculation in this version.
